# Pre-submit review: Posture 1.0.9 (2026-11-07)

Scope: every app source change from the live version 1.0.8 (`84552513`, last commit before `6c7caa14` "1.0.9 version") to `origin/main` `c49de264` (build 105). 35 commits, 57 app files: the localization pass (6 languages), the 2026-11-06 state machine fixes (practice reminder per weekday, check-in slot spacing, streak display with due refills, "Safety net" badge, phone to watch snapshot, store recovery to calibration, notification banners), paywall copy keys and 44 pt hit areas. Docs, fastlane, qa/ and tests were not reviewed as app code.

Checked and clean:
- Crashes and data loss: no new force unwraps, unchecked subscripts or `try!`. No SwiftData model or migration changes (only `PostureMode.word` removed, a computed property). `TodaySnapshot` decodes with `try?` and optional fields, so old or missing watch data reads as nil. New `@MainActor` code (`TodaySnapshot.make`, `ReminderScheduler.practiceDoneToday`, `WatchSyncService.todayDidChange`) is only called on the main actor.
- Localization crash risk: every key's format specifiers (including plural variations and `%#@n@` substitutions) match their translations in all 6 languages, checked with a strict per-argument script on top of `Tools/Localization/check.py` (0 problems).
- Purchases: RevenueCat package lookups, restore and `isEligibleForIntroOffer` (defaults to not eligible) are unchanged apart from copy keys. Paywall keeps Terms of Use and Privacy Policy links and a dismiss path. Prices come only from StoreKit.
- Streak: `displayStreak` and `record` share `freezesAfterRefill`, so the display matches what the next practice records.
- App Review strings: no treat/cure/diagnose claims in any language, no other platforms, no placeholder or debug UI outside `#if DEBUG`.
